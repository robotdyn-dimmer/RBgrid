# Theme

This directory contains theming configuration and styling utilities for the RBGrid application.

## Purpose
- Material-UI theme customization
- Color palettes and design tokens
- Typography settings
- Component style overrides
- Dark/light mode configurations

## Structure
- `palette.ts` - Color definitions
- `typography.ts` - Font and text styles
- `components.ts` - MUI component overrides
- `utils.ts` - Styling utility functions

## Guidelines
- Follow Material Design principles
- Support dark and light themes
- Use design tokens for consistency
- Keep theme configuration centralized
- Document color usage and meanings
